# RAG 消融实验方案

本实验检验：已有作家指南和固定示例的情况下，动态检索是否提升写作质量，还是仅增加成本。所有条件使用相同模型、指南、示例、主题、语气和篇幅设置，只改变参考片段来源。实验结果用于判断当前配置的增益，不把单个作者的结果推广为所有 RAG 设计的结论。

## 条件与样本

| 条件 | 风格指南 | 固定示例 | 额外参考片段 |
|---|---|---|---|
| off | 相同 | 相同 | 无 |
| rag | 相同 | 相同 | 真实 BGE 检索，经距离阈值筛选 |
| random | 相同 | 相同 | 同一公开语料中的随机片段，避开近邻及相邻文本块 |

检索命中时，random 与 rag 的片段数、每段字符数、格式和总上下文字符数相同。它用于区分“主题相关检索”与“额外风格示例”的收益；token 数可能不同，分别记录，不宣称 token 完全匹配。检索无结果时，rag 与 off 的实际提示应完全相同，作为负对照；random 则仍提供额外片段。

八个预先固定主题：故乡的狗、吹过土墙的风、村庄里的树、田野里的虫鸣、老牛与农人、村口的一条土路、深夜的地铁、一只旧闹钟。前六个本地预检能命中，后两个无合格片段。主题按生成前的检索结果分层，不根据生成质量选取或丢弃主题。

每主题重复两次，三个条件均生成，合计 48 篇。每个主题与重复构成一个配对单元，生成顺序随机。采样具有随机性，排序与随机片段选择使用固定种子，完整输出保存供复查。

Writer 为 DeepSeek Flash，非思考模式、温度 0.7、1200 token 上限；篇幅 short，沿用产品的 400–500 字设置。嵌入模型为本地 BGE，top_k=3、chunk_size=100、overlap=20、平方 L2 距离阈值 1.0。所有条件关闭额外 LLM 审稿，不自动改稿、不自动重试。

## 质量和成本测量

Pro 评委逐个评分每个配对单元的三个候选，只见匿名编号、正文、主题以及相同参考指南和固定示例，不见模型名称、条件、检索片段或规则评分。评委温度 0、非思考模式、1800 token 上限，使用 JSON 约束和结构验证。同一组以随机顺序和反向顺序各评一次，共 32 次评委调用；这是位置敏感性检查，不算增加独立样本。

主观质量分：35% 风格＋25% 自然度＋20% 语义扣题＋20% 原创观察，各维度 0–100。字数不在主观分中重复扣分，另行记录产品口径的篇幅合规率。规则审稿分不作为主要质量指标。

同时记录作者语料最长连续重复、16 字以上重复、与指南/固定示例/提供片段的最长重合、实际输入输出 tokens、模型耗时、检索耗时和含规则检查的总耗时。重复检测仅覆盖现有资料，不等价于全网原创鉴定。端到端对比主要使用预热模型及已有索引，冷启动与索引建设成本另列。

## 预先约定的分析

主要比较是检索命中主题中的 `rag - off`。辅助比较为 `rag - random` 和 `random - off`，用来定位增益来源。无结果主题单独分析，不能把相同提示的随机生成差异解释为 RAG 功效。

每篇先平均两次展示顺序评分，再计算同主题、同重复的条件差，最后先对每个主题的两次重复取均值，再对主题均值取均值。95% bootstrap 区间以**主题为单位**重采样 20,000 次，另报告主题均值的精确双侧 sign-flip 检验。有效主题只有六个，不能把 12 个重复或多次评委评分当作更多独立主题。辅助比较为探索性结果，不作多重比较后的确证结论。

将 3 分定义为实用意义界限：主效应至少 +3 且区间下界大于 0，才支持质量增益；至少 −3 且区间上界小于 0，支持质量下降；整个区间位于 −3 到 +3，可认为本轮任务范围内的收益很小。其余为结论不确定。还必须联合查看重复风险、篇幅合规和成本，不能只选一个维度宣布胜负。bootstrap 与随机化检验的假设和小样本限制仍适用。
