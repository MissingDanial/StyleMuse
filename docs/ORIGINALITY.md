# 来源复用检查与下一轮迭代

2026-10-14 第一阶段实现：来源定位、文字复用证据、独立风险状态与篇幅约束。现有写作、流式生成、后台任务和重写共用这些检查。没有新增自动模型调用；语义和情节结构复用尚未完成独立检测。

第二阶段已接入本地 BGE 句段候选与版本绑定的人工复核，具体能力、误触发和配置见 [语义候选与人工复核](SEMANTIC_REUSE.md)。自动语义裁定与整篇结构判断仍未完成。

## 第一阶段的行为

- 汇总 TXT 按 `【标题】`、`【正文】` 拆成文章，保留标题、来源 URL、分类、内容哈希、位置和来源标识。结构标签、末尾分隔线不进入正文。
- 已标为“当代名篇”的记录进入风格检索；其他明确分类只保留在来源比对中。无分类记录和普通 TXT 沿用工作区作品假设。这是初筛规则，不能代替作者归属审核；没有作者字段的汇总记录标为 `unverified`。
- 分块继承文章来源和原文位置。分块编号在整个语料内唯一，另保留文章内编号。解析版本变化会使缓存失效，向量索引随内容与元数据更新。
- 写作后比较完整来源、指南、实际提供的固定示例（最多 2,000 字）及本次动态参考。即使 RAG 关闭，固定示例也参与检查。新闻和评论虽不再用于风格检索，仍参与文字复用比对。
- Unicode 与空白规范化后比较连续文字，同时增加忽略标点的通道。近似匹配返回真实命中窗口，而不是原文开头。
- 多处短片段的生成位置取并集，统计覆盖度；重复来源和两个比较通道不会重复计数。证据保留未修改的生成文、原文及对应位置。
- 篇幅和空内容检查独立决定要求状态。超出用户选择的范围不能被综合高分或模型审稿的通过意见覆盖。本文字数口径为去空白后全部字符，包含标点和标题。

清理语料不会自动重新生成已有的指南与示例。它们还需要来源审核；当前改动提高检查可信度，尚未证明生成质量提升。

## 返回字段

原来的 `status`、`passed`、`max_common`、`similar_docs` 和 `warning` 保留，增加以下字段：

| 字段 | 含义 |
|---|---|
| `originality_status` | `low_risk`、`needs_review`、`high_risk`、`not_checked` |
| `evidence` | 原文与生成文的对应片段、来源、标题和位置，最多展示 20 条；启用语义后包含文字与语义候选 |
| `evidence_count` / `evidence_truncated` | 证据数量与是否截断展示；覆盖度计算不随展示截断 |
| `coverage` | 至少 8 个规范化字符的连续重合片段，在生成文中的区间并集及覆盖比例；近似窗口不整段计入 |
| `methods` | 已执行或尚未执行的检查方法；启用语义后 `semantic=candidates_only`，`structure` 仍为 `not_checked` |
| `scope` | 已加载来源数量、类型和检查范围；生产流程还记录原文加载是否失败 |

`max_common` 是两个文字通道的最大连续重合长度。默认 15 字仍是工程告警阈值。超过阈值为 `high_risk` / `passed=false`；出现近似匹配为 `needs_review` / `passed=null`。若至少两处短片段累计覆盖 24 字且占正文至少 15%，也提示复核。这些参数尚未经过正式文学标注集校准，告警需要结合惯用语、引用和具体表达复核。

`low_risk` / `passed=true` 表示在已加载来源中未发现上述文字告警，不能证明语义或结构原创，也不是法律结论。缺少输入或检查失败不能显示通过。覆盖比例用于定位来源复用，不能反算“原创率”。

位置为从零开始、右端不包含的 Unicode 字符区间；`line` 从 1 开始。TXT 文件统一换行后定位，EPUB 定位在提取的章节文本中，均不是文件字节位置。`offset_basis` 说明具体口径。

审稿结果另有 `requirement_status` 和 `originality_status`。历史摘要保存这两个状态，综合分数作为辅助信息。可选模型审稿只接收限定数量与长度的来源证据，不能替代全库语义与结构检查。

## 已有实验的离线复查

运行方式：

```powershell
.\.venv\Scripts\python.exe scripts/audit_originality.py --samples .stylemuse/ablations/rag-20261014/samples.json --output .stylemuse/ablations/rag-20261014/originality-v2
```

该脚本面向此次 `short` 档位的消融样本，读取保存的检索上下文和固定资料快照，输出新的 `samples.json`、`summary.json`、`report.md`。输出目录必须与原实验目录分开；不会调用写作、评审或 Embedding API，也不会修改原来的主观评分。用于其他篇幅实验时需按实际档位调整审查参数。

此次复查 48 篇：文字高风险 1 篇，为 P05-off；另外 47 篇未触发文字告警。45 篇不满足篇幅范围，其中 38 篇此前曾被规则评审判为通过。全部样本的语义与结构复用状态仍为未检查。

实际作者汇总拆成 35 条文章来源，其中 29 条通过分类初筛。BGE 索引重建为 678 个片段、512 维；所有片段的原文位置已核对，相关主题能命中，无关主题被距离阈值过滤。没有以此替代新一轮生成质量实验。

## 接下来的迭代顺序

| 阶段 | 交付 | 验收重点 |
|---|---|---|
| 1，已完成 | 来源定位、文字证据、风险状态、篇幅约束、48 篇离线复查 | 标点改动不能掩盖长段复用；近似复用不能显示通过；原文位置正确；高分不能覆盖篇幅失败 |
| 2，候选与人工流程已完成 | 独立的句段语义索引、BGE 候选召回、来源对齐与人工复核流程 | 构造改述可召回；主题与物件相近仍有误触发，需人工区分并继续改进精排 |
| 3 | 清洁语料上的四条件消融：仅指南、指南＋固定示例、指南＋动态检索、指南＋二者 | 冻结新主题集、控制输入预算、加入人工盲评；质量与复用风险分别报告 |
| 4 | 按检索价值选择是否启用、独立内容大纲与写作技巧提示 | 在新主题上验证质量收益、复用风险、篇幅合规和成本，决定默认配置 |

第二阶段先建立标注样本：直接复制、轻微修改、具体事件改述、多来源拼接、同主题独立写作、惯用表达和明确引用。按原文章划分开发与测试集，避免同一作品泄漏到两边。评价候选召回率、误报与漏报、定位准确性；用这些结果校准阈值。风格检索距离不能直接作为抄袭概率。

主题匹配当前仍是文字启发式，语气未独立检测；它们不应被包装成可靠的语义合规结论。后续需要与语义检测一起建立可解释的判题基准。
